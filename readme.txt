Start taking Stripe Payments on your WordPress site in 2 minutes.

== Description ==

Payment Suite is the easiest way to start taking credit card payments on your site. This Stripe Payments Plugin works out of the box, letting you create a payment gateway in less than 2 minutes.

Just add your Stripe keys and set your price, then add the shortcode [stripe_checkout] anywhere in your content to add a checkout with Stripe button.

The checkout button sends users to a secure Stripe Checkout. Once the payment is complete, send the user to a payment confirmation page of your choice.

= About Stripe = 

Stripe is the world's leading online payment processor, and the easiest way to monetize an online business.

Payment Suite is designed specifically to integrate with Stripe because of how easy they make it to accept online payments.

Stripe has no setup fee, no recurring monthly fees, just a small percentage of each sale you make.

By integrating with Stripe, Payment Suite is able to take advantage of Stripe Checkout, a simple, conversion-optimized payment page built and hosted by Stripe.

This payment page is responsive and optimized for different devices, and accepts 135+ currencies, multiple credit card options, as well as Apple Pay and Google Pay.

When you send potential customers to Stripe Checkout, you'll get more conversions, as your customers will find it much easier and safer to give you money.

See here for more on Stripe and how it works:

- [About Stripe Checkout](https://stripe.com/en-gb-us/payments/checkout)
- [Stripe supported countries](https://stripe.com/global)
- [Create an account](https://dashboard.stripe.com/register)

== Installation ==

1. Upload the Payment Suite plugin file to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. In your sidebar, select Payment Suite and setup the plugin.
4. Add the shortcode [stripe_checkout] anywhere to add a checkout with Stripe button.

= Do I Need A Stripe Account To Use Payment Suite? =

Payment Suite is designed as a Stripe Payment Gateway, so you will need a Stripe account to start accepting payments.
